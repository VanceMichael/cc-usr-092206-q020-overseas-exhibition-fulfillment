# 海外展会本地化履约

支持海外商品展从参展准备、现场对接到本地渠道和订单落地。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括中国参展企业、马来西亚采购商、本地渠道伙伴、展会主办方。

资料所依据的领域事实如下：

- 展会从产品展示向产业对接转型
- 新议题包括跨境电商、人工智能商业应用和宠物消费
- 主办方计划在展后持续跟进商贸配对成果

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
